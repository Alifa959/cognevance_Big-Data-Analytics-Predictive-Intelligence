# Complete Workflow

1. Select a public e-commerce dataset.
2. Place it in data/raw/orders.csv.
3. Inspect columns and data quality.
4. Run data preprocessing.
5. Generate exploratory analysis.
6. Create SQL database and load clean data.
7. Run SQL KPI queries.
8. Process the large dataset with PySpark.
9. Create customer-level features.
10. Train and evaluate the churn model.
11. Aggregate sales monthly.
12. Train and validate SARIMA.
13. Export predictions.
14. Build Power BI dashboards.
15. Write findings and business recommendations.
16. Prepare report and presentation.
17. Push the complete project to GitHub.
